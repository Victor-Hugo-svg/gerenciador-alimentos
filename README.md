# Gerenciador de Validade de Alimentos 🍎



[![CI do Gerenciador de Alimentos](https://github.com/Victor-Hugo-svg/gerenciador-alimentos/actions/workflows/ci.yml/badge.svg)](https://github.com/Victor-Hugo-svg/gerenciador-alimentos/actions/workflows/ci.yml)



**Versão atual:** 1.0.0



## 🎯 O Problema (Dor Real)

O desperdício doméstico de alimentos é um problema ambiental e financeiro grave. Muitas pessoas compram itens para a despensa ou geladeira e esquecem deles até que passem da data de validade, resultando em descarte desnecessário.



## 💡 A Solução

Uma aplicação CLI (Command Line Interface) simples que permite ao usuário registrar os alimentos e suas datas de validade. O sistema possui um alerta inteligente que filtra e exibe apenas os alimentos que estão prestes a vencer (nos próximos 3 dias), ajudando o usuário a priorizar o consumo.



## 👥 Público-Alvo

Qualquer pessoa responsável pelas compras ou gestão de cozinha da casa que deseje economizar dinheiro e reduzir seu impacto ambiental.
